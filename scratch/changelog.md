# Changelog - HN 24h (Hacker News Daily Digest)

บันทึกประวัติการพัฒนาและปรับปรุงระบบดึงข้อมูลและสรุปข่าว Hacker News ประจำวันภาษาไทย (รุ่น MVP สำเร็จรูป)

## [1.0.0] - 2026-06-04

### Added (สิ่งที่เพิ่มเข้ามาใหม่)
- **ระบบคลังความรู้ถาวรด้วย SQLite (`hn_knowledge_base.db`)**: 
  - ออกแบบฐานข้อมูลสำหรับเก็บข้อมูลข่าวดิบและบทสรุปภาษาไทยอย่างยั่งยืน
  - เพิ่มโมดูล Full-Text Search (FTS5) สำหรับรองรับการเสิร์ชค้นหาข้อมูลในเนื้อหาบทสรุปภาษาไทยและหัวข้อข่าวภาษาอังกฤษได้ในอนาคต
  - พัฒนาโครงสร้างความสัมพันธ์ Many-to-Many สำหรับการกรองและจัดหมวดหมู่ข่าวสารตาม **แท็ก** (เช่น `zig`, `ui`, `ai`)
- **ไฟล์สาธิตคิวรี่ฐานข้อมูล (`scratch/sqlite_demo.py`)**: เพิ่มตัวอย่างการคิวรี่ดึงข่าวตามแท็ก และค้นหาคำแบบรวดเร็ว
- **กฎระเบียบแนะนำการใช้เครื่องมือประจำระบบทำงาน (`rules.md`)**: 
  - กำหนดให้เลือกใช้เครื่องมือความเร็วสูงในโปรเจกต์เป็นอันดับแรก ได้แก่ `uv` (สำหรับ Python), `bun` (สำหรับ JavaScript/TypeScript) และ `ripgrep` (สำหรับการค้นหาคำ)
  - เพิ่มข้อกำหนดในการมุ่งเน้นสถาปัตยกรรมของ **Antigravity 2** และเพิกเฉยต่อแนวคิด/ข้อจำกัดเก่าของ Antigravity 1 ทั้งหมด
- **ประวัติบันทึกการทำงานและคู่มือศึกษาโค้ด**: เพิ่มโฟลเดอร์สำรองซอร์สโค้ดและข้อมูลทดสอบ [scratch/](file:///d:/gampol/agy/hn24h/scratch/) สำหรับศึกษาแนวทางในอนาคต

### Changed (สิ่งที่ปรับปรุงแก้ไข)
- **ขยายจำนวนการดึงข่าวสูงสุด**: ปรับปรุงสคริปต์ [fetch_hn.py](file:///d:/gampol/agy/hn24h/fetch_hn.py) ให้ดึงและประเมินข่าวยอดนิยมได้สูงสุดถึง **40 ข่าว** (โดยสำรวจข้อมูลลึก 5 หน้าจาก Algolia Search API) และบันทึกข้อมูลดิบตรงเข้า SQLite
- **อัปเกรดความยาวและคุณภาพบทสรุปภาษาไทย (แก้ปัญหา Token Limit)**:
  - ปรับเปลี่ยนแนวทางจากการสรุปรวมข่าวกองโตพร้อมกัน มาเป็นการส่งข้อมูลให้เอเจนต์สรุปแยกแบบ **Chunk ละ 5 ข่าว**
  - ผลลัพธ์ในหน้า HTML รายงานมีความยาวและเจาะลึกขึ้นมาก โดยระบุทั้งหัวข้อข่าว จุดเด่นเชิงโครงสร้าง และรายละเอียดประเด็นดราม่ารวมถึงเสียงโต้แย้งในบอร์ด HN ได้ชัดเจนขึ้น
- **ปรับแต่งหน้าตา HTML พรีเมียมให้อ่านง่ายสำหรับผู้สูงอายุ (`build_html.py`)**:
  - ขยายขนาดตัวหนังสือหลัก (`body`) เป็น **18px** และปรับระยะห่างบรรทัดเป็น **1.75** สบายตาขึ้นโดยไม่ต้องกดขยายหน้าจอซูม 125%
  - ดึงข้อมูลข่าวดิบและบทสรุปจาก SQLite โดยตรงเพื่อประกอบเป็น Static HTML รายวัน
- **ระบบทำความสะอาดอัจฉริยะ (Self-cleanup)**: สคริปต์จะทำการอิมพอร์ตข้อมูลสรุปตกค้างใน JSON ลงฐานข้อมูล SQLite อัตโนมัติ จากนั้นลบไฟล์ JSON ย่อยและไฟล์ข้อความดิบชั่วคราวออกไปอย่างสะอาดหมดจด
